## acesms 1.1.0

- SMSのVDPカウンターと割込み、スプライトのオーバーフロー、横スクロールのタイミングを改善しました。
- BIOSなしで起動するSMSのVDP初期値を補い、`SMS Sprite Test (PD)` が表示されるようになりました。
- 1.0.0と1.0.1のステートを復元できます。1.1.0で保存・上書きしたステートは形式版2になります。
- 1.1.0で最初に開いたDBはスキーマ版3に更新されます。既存の設定、SRAM、ステート、チートは引き継がれます。1.0.1以前では、版3のDBを開けません。

### 更新と起動

1. 旧版を正常終了し、`acesms.exe` の横にある `acesms.sqlite3` をバックアップします。
2. Assetsの `acesms-1.1.0-win64.zip` を書込み可能な別フォルダへ展開します。
3. DBのコピーを新しい `acesms.exe` の横に置いて起動します。旧版に戻す場合は、旧本体と更新前のDBを使います。

初めて使う場合は、展開した `acesms.exe` を起動し、File → Open ROM… で手元のROMを開いてください。 [日本語マニュアル](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.1.0/docs/PACKAGE.md)

## English

- Improved SMS VDP counter, interrupt, sprite overflow, and horizontal scroll timing.
- Initialized the SMS VDP registers required by `SMS Sprite Test (PD)` when booting without a BIOS.
- Save states from 1.0.0 and 1.0.1 can still be loaded. States saved or overwritten by 1.1.0 use format version 2.
- The first time 1.1.0 opens a database, it upgrades it to schema version 3 and preserves settings, SRAM, save states, and cheats. Version 1.0.1 and earlier cannot open a schema version 3 database.

### Updating and starting

1. Close the old version normally and back up `acesms.sqlite3` from the folder containing `acesms.exe`.
2. Extract `acesms-1.1.0-win64.zip` from Assets to a separate writable folder.
3. Put a copy of the database next to the new `acesms.exe` and start it. To roll back, use the old executable and the pre-upgrade database.

For a fresh installation, start the extracted `acesms.exe` and use File → Open ROM… to open your ROM. [English manual](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.1.0/docs/PACKAGE.md#english)
