## acesms 1.0.1

- 1P XInputでステート保存・復元、スロット選択、高速駆動、全画面を操作できます。初期割り当てはLB／RBで保存／復元、LT／RTで前／次のスロット、LS／RSで高速駆動／全画面の切替です。Settings → Controller Configuration → XInput shortcuts… で各操作を変更・解除できます。
- ステートスロットを切り替えると、ウィンドウ・全画面とも左上に約2秒、番号と保存日時・タイトルを表示します。
- Sega Mapperを使う768 KiBのSMS ROMに対応しました。48バンクの折り返しは実機未照合です。
- 日本語IMEの漢字モードを同時押しと誤判定して、コントローラー設定のキー割り当てが進まない問題を修正しました。

### 1.0.0から更新する

1. 1.0.0を正常終了し、実行ファイルの横にある `acesms.sqlite3` をバックアップします。
2. Assetsから `acesms-1.0.1-win64.zip` をダウンロードし、書込み可能な別フォルダへZIP全体を展開します。
3. DBのコピーを新しい `acesms.exe` の横に置いて起動します。DBは版2へ更新され、共通設定、ROM設定、SRAM、ステート、チートが引き継がれます。既存のゲーム操作と競合するショートカットは未割り当てで始まります。1.0.0に戻す場合は旧本体と更新前のDBを使います。

初めて使う場合は、展開した `acesms.exe` を起動し、File → Open ROM… で手元のROMを開いてください。 [日本語マニュアル](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.0.1/docs/PACKAGE.md)

## English

- Player 1 can use XInput to save or load a state, change slots, and toggle fast forward or fullscreen. The defaults are LB/RB for save/load, LT/RT for previous/next slot, and LS/RS for fast forward/fullscreen. Change or clear each binding under Settings → Controller Configuration → XInput shortcuts….
- When you change save-state slots, a notice in the upper-left corner shows the slot number, save time, and title for about two seconds in windowed and fullscreen modes.
- Added support for 768 KiB SMS ROMs that use the Sega mapper. The 48-bank wrapping behavior has yet to be verified on hardware.
- Fixed keyboard binding in controller settings when the Japanese IME's Kanji mode was misread as another held key.

### Upgrading from 1.0.0

1. Close 1.0.0 normally and back up `acesms.sqlite3` from the executable's folder.
2. Download `acesms-1.0.1-win64.zip` from Assets and extract the entire ZIP to a separate writable folder.
3. Place a copy of the database next to the new `acesms.exe` and start it. The database upgrades to schema version 2 and retains global settings, ROM settings, SRAM, save states, and cheats. Any new shortcut that conflicts with an existing game binding starts unassigned. To return to 1.0.0, use the old executable and the pre-upgrade database backup.

For a fresh installation, start the extracted `acesms.exe` and use File → Open ROM… to open your ROM. [English manual](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.0.1/docs/PACKAGE.md#english)
