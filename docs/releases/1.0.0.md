## acesms 初版

acesms（ACoward's Emulator Sega Master System）は、Windows 11 x64向けのSega Master System、Game Gear、SG-1000エミュレーターです。初版では、ROMごとの設定・SRAM・セーブステートをSQLiteデータベースに保存できます。

### 起動方法

1. このリリースの Assets から `acesms-1.0.0-win64.zip` をダウンロードします。
2. ZIP全体を書込み可能なフォルダーに展開し、`acesms.exe` を起動します。Microsoft Visual C++のx64ランタイムが必要です。
3. **File → Open ROM…** で手元のROM（`.sms`、`.gg`、`.sg`、`.zip`）を選ぶか、メインウィンドウにドロップします。初回は設定を確認し、**Register and open** を選びます。

操作、設定、セーブデータのバックアップ方法はマニュアルに記載しています。 [日本語マニュアル](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.0.0/docs/PACKAGE.md)

## English

This is the first release of acesms (ACoward's Emulator Sega Master System), a Sega Master System, Game Gear, and SG-1000 emulator for Windows 11 x64. It stores settings, SRAM, and save states for each ROM in a SQLite database.

### Getting started

1. Download `acesms-1.0.0-win64.zip` from the Assets section of this release.
2. Extract the entire ZIP to a writable folder and run `acesms.exe`. The Microsoft Visual C++ x64 runtime is required.
3. Use **File → Open ROM…** to select a ROM file (`.sms`, `.gg`, `.sg`, or `.zip`), or drop it onto the main window. When opening a ROM for the first time, confirm its settings and select **Register and open**.

See the manual for controls, settings, and save-data backups. [English manual](https://github.com/ACoward-Kakuyomu/acesms/blob/v1.0.0/docs/PACKAGE.md#english)
